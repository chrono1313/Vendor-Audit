Vendor Audit

A passive, evidence-based check of a domain's DNS, email, TLS, and HTTP posture.

Type a domain (or paste a URL — schemes and paths are stripped). The audit checks SPF, DMARC, DKIM, MX, MTA-STS, TLS-RPT, DNSSEC, CAA, RPKI, IPv6, TLS configuration, HSTS, HTTP/2 and HTTP/3 support, security headers, cookie attributes, EOL libraries and operating systems, and more — about 60 scored checks against published RFCs, W3C specs, OWASP guidance, and CA/Browser Forum baselines.

Every finding cites the standard it's measured against. The result is a score, a category breakdown, and a list of findings suitable for sharing with the audited domain's technical team.

This service is passive: it reads what the domain voluntarily publishes (DNS, HTTPS GET, public APIs). It does not port-scan, brute-force, or probe for vulnerabilities. The full source is on GitHub; the same tool is available as a CLI for batch use, deep-mode checks, and SSL Labs integration.
