Vendor Audit

A passive check of a domain's best-practice alignment.

What it's for

Vendor Audit is a due-diligence tool. Run it on a vendor's domain before purchasing a product or service, or on your own, to get a quick, evidence-based read on how the configuration aligns with current best practices. Findings aren't a deal-breaker on their own, but they're a useful conversation starter and a data point alongside everything else you're evaluating.

Vendor Audit measures how closely a domain follows published best practices for email, DNS, TLS, and web delivery. Many of these practices are security controls, but this is not a security assessment: it doesn't look for vulnerabilities, and a clean report doesn't mean a vendor is secure. It shows how a domain's public configuration compares with current published standards.

Share it with the vendor

Every report can be downloaded as a text file or a web page. Please share the text report with the vendor. Every section cites the RFC, W3C spec, OWASP guidance, or CA/Browser Forum baseline it's measured against — so the report reads as feedback, not as an accusation. Most vendors appreciate a heads-up they can act on; the text report gives them one in a form they can take straight to the people who can address it. When more than one prospect shares these reports with the same vendor, they're more likely to prioritize the issues raised.

Checks that don't apply are skipped, such as mail checks for a domain that receives no mail. Each finding is rated Critical, High, Medium or Low. Optional practices are listed as informational and are never counted.

How it checks

This service is passive: it reads what the domain voluntarily publishes — DNS records, a handful of ordinary web requests and TLS handshakes, and public routing data. With Deep checks it also connects to the domain's mail servers. It does not port-scan, brute-force, or probe for vulnerabilities.

The full source is on GitHub; a CLI is also available for batch use, SSL Labs integration, and bulk audits.

Privacy. Visitor IP and submitted domain are logged for 30 days for abuse prevention. Traffic passes through Cloudflare, whose privacy policy also applies.
